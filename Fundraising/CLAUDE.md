# Fundraising DD — Project Context

## What this project is
Sego Therapeutics seed fundraising due diligence. This folder contains investor DD Q&A docs, pitch decks, and a canonical DD Response Playbook.

## Folder structure
- **due-diligence/** — Investor DD question docs + DD_Response_Playbook.md (canonical answers by theme)
- **pitch-materials/** — Master deck, investor-specific decks
- **references/target-deep-dives/** — Target deep dive decks (ACP3, KLK2, CLDN1, CEACAM5, MUC1-C, GCC), target selection process overview, and target prioritization scoring spreadsheet

## Key context
- **Company:** Sego Therapeutics — cyclic peptide radioligand therapy (RLT) platform, Salt Lake City
- **Stage:** Seed round; Series A targeted mid-2028
- **Lead programs:** ACP3 and KLK2 (prostate cancer), entering clinic early 2028
- **Pipeline:** 6 targets (ACP3, KLK2, CLDN1, CEACAM5, MUC1-C; GCC deprioritized for in-license slot)
- **Key investors in DD:** Avidity Partners, Polaris Partners, Avego (CurieBio)
- **Founding investor:** Wasatch Group ($20M equity + build support)

## Writing standards
- Always use /sego-writing-style and /stop-slop skills for external prose
- Answer-first: lead with the conclusion
- Quantitative thresholds early; comparative framing (RLT vs ADC/EBRT, peptides vs antibodies)
- Confident, non-defensive tone — no hedging, no filler
- Cite sources with date; flag gaps explicitly rather than fabricating
- Citation format: Last name, Journal, Year — e.g., (Hofman, Lancet Oncol, 2025)
